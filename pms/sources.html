Methodology notes

  • No invented numbers. Derived fields are only MoM/YoY differences and percentage shares, clearly labeled.
  • AUM MoM change ≠ net flows (includes mark-to-market).
  • APMI industry series footnotes: (1) Discretionary includes EPFO/PF; (2) Advisory is value of assets under advisory.
  • Desktop layout (viewport width 1280) to match the AMFI dashboard set.
  • Strategy performance pages behind interactive filters; first version scrapes public IaInsight HTML for listed Kotak equity/thematic IAs.
