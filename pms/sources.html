Methodology notes

  • No invented numbers. Derived fields are only MoM/YoY differences and percentage shares, clearly labeled.
  • AUM MoM change ≠ net flows (includes mark-to-market).
  • APMI industry series footnotes: (1) Discretionary includes EPFO/PF; (2) Advisory is value of assets under advisory.
  • Desktop layout (viewport width 1280) to match the AMFI dashboard set.
  • Strategy performance: the full APMI IA performance table is pulled per strategy type, service type and benchmark (research/scrape_ia_perf.py); APMI Insights data via research/fetch_insights.py. Peer categories follow APMI's grouping (strategy type + service type + benchmark).
  • Level playing field: each Kotak IA is compared only with peers in that same APMI group who report a 3-year TWRR and have AUM ≥ ₹250 cr. A Kotak IA that fails a filter is still shown, with a note. Customised variants are not merged. APMI has only four broad categories; the official benchmark is used as a style proxy. Excess return is omitted because the IA performance table does not include benchmark index returns. Risk measures (volatility, drawdown, Sharpe) are omitted because APMI does not publish them. A figure of 0.00 is treated as not reported.
  • Peer brand roll-ups sum all registered APMI entities of a group (e.g. 360 ONE's three PMS entities).
